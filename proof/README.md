
# Travel.pk Umrah Trip Planner Prototype

## Run locally
1. Open `proof/index.html` in a browser, or use VS Code Live Server.
2. Select a planning option and complete the trip preference form.
3. Submit the form to review the request summary.

## Scope
This is a standalone front-end prototype. It does not connect to Travel.pk, retrieve live hotel inventory, or send enquiries. Hotel availability, prices, and distances must be confirmed by Travel.pk.
